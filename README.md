# AI-Food-Detection-and-Recipe-Chatbot
This is a mobile app with a server backend,that takes or upload a food photo. The app names the dish and gives a recipe, estimated nutrition and allergen info, and top YouTube tutorials. It also has a shopping list, scan history, user accounts and “Chef Latifa”, a food-only AI chatbot.
Tools: React Native (Expo) for the app, Django REST Framework for the backend, JWT for login, a Swin Transformer food classifier (PyTorch and Hugging Face), Google Gemini for recipes and chat, the YouTube API for videos, and Docker for deployment.
